jobbot privacy policy

Last updated: November 19, 2026

jobbot is a personal tool run by its only user, Ritvik Pandillapally, on his own computer. It is not available to anyone else.

What Google data it accesses

  • Gmail: reads messages related to job applications (confirmations, verification codes, recruiter replies), applies labels to them, and creates draft follow-up emails. It does not send email on its own.
  • Google Calendar: creates events for interviews and assessments.

How the data is used and stored

Data is used only to track the owner's own job applications. It is processed and stored locally on the owner's computer. Sign-in tokens are kept in the operating system's credential store. Data is not sold, shared with third parties, or used for advertising.

Short excerpts of job-related emails may be sent to an AI model provider (Anthropic) solely to classify them for the owner.

Google API Services User Data Policy

jobbot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting jobbot's local data folder removes all stored data.
